# 股市宏观看板

实时行情看板：A股 / 港股 / 美股 / 板块 / 快讯一屏速览，支持 **10 秒自动刷新** 与 **点击下钻查看详情**。

---

## 快速开始

双击 **`start.bat`** 即可（自动启动服务并打开浏览器）。

或手动：

```bash
python server.py
# 浏览器访问 http://localhost:8765/dashboard.html
```

> ⚠️ 必须通过 `server.py` 启动才能获取实时数据。
> 浏览器无法直接请求行情接口（CORS 限制），`server.py` 充当本地代理。
> 若直接双击 `dashboard.html`，看板会显示最近一次缓存数据并提示"离线"。

## 功能

| 功能 | 说明 |
|------|------|
| **10 秒自动刷新** | 可通过顶部开关随时关闭/开启，右侧显示下次刷新倒计时 |
| **手动刷新按钮** | 点击立即拉取最新行情 |
| **点击下钻** | 指数卡 → 东财分时/K线页；板块 → 板块行情页；快讯 → 原文详情页 |
| **数据变化闪烁** | 数值更新时红色/绿色高亮提示 |
| **红涨绿跌 / 绿涨红跌** | 顶部一键切换 A股 / 美股配色惯例 |
| **离线降级** | 服务不可用时自动显示缓存数据并给出提示 |

## 架构

```
浏览器 (dashboard.html)
   │  fetch /api/dashboard  ← 每 10 秒
   ▼
本地代理 (server.py)  ← 解决 CORS，带 TTL 缓存与请求节流
   │
   ├─ 东财 ulist.np  → 指数行情（8 个 A股 + 7 个全球，单次请求）
   ├─ 腾讯板块接口    → 31 个行业板块（单次请求，本地排序出三榜 + 汇总涨跌家数）
   ├─ 东财涨跌停池    → 涨停 / 跌停家数
   └─ 东财快讯接口    → 7×24 财经快讯（含原文 URL）
```

### 缓存策略

| 数据 | TTL | 请求成本 |
|------|-----|----------|
| A股 + 全球指数 | 5 / 20 秒 | 各 1 次 |
| 涨跌停家数 | 45 秒 | 2 次 |
| 板块 + 涨跌家数 | 45 秒 | 1 次 |
| 财经快讯 | 45 秒 | 1 次 |

**上游保护**：全局请求节流（最小间隔 150ms）+ 指数退避重试（最多 3 次）+ 失败回退旧缓存。

> 设计取舍：全市场逐页统计涨跌家数需 50+ 次请求，实测会触发东财 `clist` 接口限流，
> 故改用「全部行业板块的涨跌家数求和」（单次请求），口径已在界面标注。

## 常见问题

**Q：显示"离线"怎么办？**
A：确认 `server.py` 正在运行，且访问地址是 `http://localhost:8765/dashboard.html`（而非直接双击 HTML 文件）。

**Q：端口 8765 被占用？**
A：设置环境变量 `DASHBOARD_PORT` 指定其他端口。

**Q：板块/快讯为空？**
A：上游接口偶发限流时会保留上次数据，稍后自动恢复。看板不会因此崩溃。
